# CSC 746 Homework Latex Template

This project contains the latex sources and related content that will form the basis for your technical project writeups in CSC 746.

The simplest way to make use of this latex template is to first clone the project on your local machine, create a free account on overleaf.com, click on "New Project", then "Upload project". Overleaf will build these files into a high quality technical writeup, and you can download the article as a PDF.

Look through each of the latex files where you will see hints about what kinds of information should go into each section. 

For 746 writeups, please adhere to the document structure contained in this latex template.
